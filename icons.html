Icons & Items

Configure icon appearance using item data components.

Basic Structure

Every icon needs at minimum a material. Its appearance is customized through an optional components block, which mirrors the vanilla data-component format using kebab-case keys.

config.yml
title-icon:
  symbol: 'T'
  material: 'player_head'
  components:
    custom-name: '<gradient:#FCBDE3:#F973C4>Brew Market</gradient>'
    lore:
      - '<gray>Sell your finest brews!</gray>'
    profile:
      properties:
        - name: 'textures'
          value: 'eyJ0ZXh0dXJlcyI6...'

Data Components

All of the following go under the icon's components block:

ComponentTypeDescription
custom-nameStringDisplay name (MiniMessage)
loreListLore lines (MiniMessage)
profileObjectHead profile (properties list of name/value)
enchantmentsMapEnchantment : level
enchantment-glint-overrideBooleanForce or disable the enchant glint
custom-model-dataObjectResource pack data (floats, flags, strings, colors)
item-modelStringResource location for the item model
potion-contentsObjectPotion custom color
tooltip-displayObjectTooltip visibility control
tooltip-styleStringCustom tooltip style
Names and lore are per-viewer: custom-name and lore are rendered for each player and support MiniMessage plus PlaceholderAPI placeholders. The remaining components are structural and baked into the item once.

custom-name & lore

Both accept MiniMessage and PlaceholderAPI placeholders and are rendered for each viewer.

config.yml
components:
  custom-name: '<gradient:#FCBDE3:#F973C4><b>Sell drink</b></gradient>'
  lore:
    - ''
    - ' <white>Place your brews below and...</white> '
    - ' <white>Sell them for money!</white> '
    - ''

profile

config.yml
profile:
  properties:
    - name: 'textures'
      value: 'eyJ0ZXh0dXJlcyI6eyJTS0lOIjp7InVybCI6Imh0dHA6...'

Forces the material to player_head. A bare player name also works: profile: 'Notch'.

enchantments

Keys are Minecraft enchantment ids (no minecraft: prefix); values are the levels.

config.yml
enchantments:
  unbreaking: 3
  sharpness: 5

enchantment-glint-override

Forces the enchant glint on or off, regardless of enchantments.

config.yml
enchantment-glint-override: true

custom-model-data

Four independent optional lists for resource packs. Include only the ones you need. Colors are packed RGB integers.

config.yml
custom-model-data:
  floats:
    - 0.5
    - 1.0
  flags:
    - true
  strings:
    - 'custom_variant'
  colors:
    - 16679863

item-model

A namespaced key (namespace:path) pointing to the item model to render.

config.yml
item-model: 'minecraft:diamond_sword'

potion-contents

Sets the potion's custom color (packed RGB integer). Only applies to potion materials.

config.yml
potion-contents:
  custom-color: 16679863

tooltip-display

config.yml
# Hide entire tooltip
tooltip-display:
  hide-tooltip: true

# Or hide specific parts
tooltip-display:
  hide-tooltip: false
  hidden-components:
    - 'potion-contents'
    - 'enchantments'

tooltip-style

A namespaced key (namespace:path) for a custom tooltip style from a resource pack.

config.yml
tooltip-style: 'myresourcepack:fancy'

Decorative Icons

Decorative icons fill the non-functional slots in your GUI layout — the ones marked with symbols like J, K, or L in market.layout. They are purely visual: players cannot interact with them, and they have no sell behavior. Their main purpose is to frame the item slots and sell buttons, making the market GUI look polished instead of leaving empty grey slots.

It is good practice to set hide-tooltip: true on decorative icons so players do not see a floating item name when hovering over them.

config.yml
decorative-icons:
  pink-glass:
    symbol: 'J'
    material: 'pink_stained_glass_pane'
    components:
      tooltip-display:
        hide-tooltip: true
  brain-coral:
    symbol: 'K'
    material: 'brain_coral'
    components:
      tooltip-display:
        hide-tooltip: true
  brain-coral-fan:
    symbol: 'L'
    material: 'brain_coral_fan'
    components:
      tooltip-display:
        hide-tooltip: true
